Describe que hacen los siguientes comandos de git, escribe su descripcion al frente en una sola linea.

git status: Este comando se usa para obtener el estado actual del repositorio

git clone: Clona un repositorio desde el remoto hacia el local 

git pull: Obtiene los cambios realizados de la version el repositorio hacia el remoto

git checkout: cambia dentro de las diferentes ramas que existen

git log: Genera el listado de cambio o veriones generadas de los commit realizados

git branch: Genera una nueva rama a partir de la version actual

git add: Genera un nuevo cambio 

git commit: Guarda los cambios realizados en el repositorio local

git push:  Genera o envia los cambios al repositorio remoto

git merge: Cobina los cambios que se hicieron en dos ramas diferentes
